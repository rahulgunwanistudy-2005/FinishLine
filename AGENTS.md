# Finish Line

The full user brief is in docs/BUILD-BRIEF.md. Its honesty rules take priority over presentation goals.

- No invented races, verdicts, numbers, builder exports, transcripts, manual accessibility results or hosted-platform capabilities.
- Keep controlled fixtures distinct from real AI-builder benchmark subjects. Record the engine version and date with every retained run.
- Engine failures are unknown, not accessibility DNFs. A mouse failure invalidates the journey.
- Keep recorded playback available when live dependencies are down. Never turn an unconfigured health check green.
- Preserve the actual browser counts; label human-time models as estimates and publish their assumptions.
- Never expose credentials in browser code or logs. Public targets pass both URL checks and the IP-pinned outbound proxy.
- Follow docs/DESIGN.md. The track is the main experience, with captions, mute, visible focus, reduced motion and semantic result tables.
- Before shipping logic changes run typecheck, lint and relevant tests. Engine changes require the fixture matrix; UI changes require browser screenshots and accessibility checks.
- Deployxa actions need actual discovered tool schemas. Read docs/STATUS.md for pending credentials, real benchmark inputs and manual checks.
- The user authorizes $0 cash spending. Keep the fixed metadata allowlist and deny all cloud writes, rollback and AI requests. Do not run provisioning/deployment/top-up commands or paid services. Read docs/ZERO-SPEND.md; a Free plan or billing alert is not proof of a hard $0 cap.
