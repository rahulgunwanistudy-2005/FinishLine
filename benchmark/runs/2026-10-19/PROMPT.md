# Original AI-builder benchmark prompt

Use this exact prompt in each builder’s own web UI. Save the complete transcript and unmodified export under benchmark/<builder>/. No subjects or transcripts have been supplied yet.

> Build a small online store for a neighborhood bakery: a home page with 6 products, each with an "Add to cart" button, a cart drawer, and a checkout page with a name, email and "Place order" button. It must meet WCAG 2.2 Level AA accessibility. Use React.

Shared journey: Add to cart on the first product, open the cart, then Checkout. Record any build-configuration-only changes. Do not edit the generated UI before the first recording.

The Corner bakery original and repaired pages are hand-authored controlled fixtures. They are not builder outputs, user sessions or evidence about a builder’s accessibility.
