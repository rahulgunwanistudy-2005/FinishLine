- Browser errors: none in the production route/playback checks.

Zero axe violations and no document overflow. The UI test intercepts only API transport to keep production private-URL restrictions intact; no fabricated race is submitted. - Start/replay, final results, evidence dialog open/close and reduced-motion final results were exercised by the browser-check script.
- The actual homepage Start race self-race completed in all six lanes. It is a one-step self-check, not comprehensive coverage of every workflow. Its dated recording is retained with the benchmark fixtures.

Reports: `docs/a11y-results.json`, `docs/lighthouse.json`; screenshots in `docs/screenshots/`.

The first audit identified faint lane numbering and accessible names that did not include all visible text. Both were corrected before the zero-violation run. Google Fonts are now served locally, static assets use Brotli/gzip, and schema code is kept out of the browser bundle to improve loading.

Final delivery checks reduced the controlled race JSON from 32,299 bytes to 5,691 bytes with Brotli. Critical font/app styles are inlined and deep links serve precompressed HTML. Earlier attempts are also retained: `lighthouse-chromium141-before.json` (84), `lighthouse-chromium141-after.json` (84), and `lighthouse-contended.json` (37, with a CPU warning and high observed response latency). Tool/browser versions, flags and host load differed, so the full score change must not be attributed solely to compression. The final three-run summary records the comparison method.
